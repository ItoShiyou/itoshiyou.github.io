Focus Wave プライバシーポリシー

最終更新日: 2026年10月23日

Focus Wave（以下「本アプリ」）は、環境音の再生とアラーム通知を提供します。

収集する情報

本アプリはアカウントを作成せず、氏名、連絡先、音声を収集しません。追加した音声、音源の配置、カスタムプリセット、アラーム設定は端末内に保存され、開発者のサーバーへ送信しません。iOS版では無料提供のため、Google Mobile Ads SDK を使ったバナー広告を表示します。

広告と第三者サービス

Google Mobile Ads SDK は広告の配信、測定、不正防止、サービスの維持のため、IP アドレス（おおよその地域の推定に使われる場合があります）、端末識別子、広告の表示・操作情報、診断情報やパフォーマンス情報などを収集または処理することがあります。情報の取り扱いは Google および広告パートナーのポリシーに従います。詳細は Google のプライバシーポリシーと Google Mobile Ads のデータ開示をご確認ください。

地域や法令に応じて、アプリ内に同意画面が表示されます。必要な場合はアプリ内のプライバシー設定から同意内容を確認または変更できます。端末のプライバシー設定も広告の利用に影響する場合があります。

端末内での保存と処理

アラーム時刻と有効状態は、アプリの設定としてお使いの端末内に保存されます。アラームは iOS のローカル通知として端末に登録されます。環境音はアプリに含まれる音声ファイルを端末上で再生します。MP3・M4A・WAVをファイル選択画面から読み込めます。マイクや録音機能は使用しません。端末内の保存情報はアプリの削除により削除できます（iOSのバックアップは端末の設定に従います）。

第三者への提供

広告に関する情報は上記の第三者サービスにより処理されます。通知の配信は iOS の通知機能によって端末上で行われます。

ウェブ版について

ウェブ版では Google Mobile Ads SDK を使用しません。ページの配信に GitHub Pages を使用します。GitHub によるアクセスログ等の取り扱いは GitHub のプライバシー声明に従います。
